# **App Name**: Sakura Portfolio

## Core Features:

- Landing Page Showcase: Elegant landing page showcasing your skills and projects.
- Interactive Project Gallery: Visually appealing project display with images and descriptions.
- Contact Form Submission: Contact form submission sends an email to mishrashaswati2005@gmail.com
- Responsive Layout: Clean, responsive design that adapts to different screen sizes.

## Style Guidelines:

- Primary color: Soft cherry blossom pink (#F7CAD0) to evoke a sense of serenity and beauty.
- Background color: Desaturated light pink (#F9E4E6), creating a gentle and calming backdrop.
- Accent color: Muted lavender (#E0BBE4) for interactive elements, complementing the pastel palette.
- Body and headline font: 'ZCOOL XiaoWei' (serif) for a traditional Chinese aesthetic, adding elegance and cultural relevance.
- Delicate, hand-drawn-style icons of cherry blossoms, traditional Japanese patterns, and relevant project-related symbols, with an emphasis on calligraphic brush strokes.
- Clean and minimalist layout with ample whitespace to create a sense of calm and highlight the showcased work. Asymmetrical arrangements can enhance visual interest.
- Subtle animations, such as a gentle fade-in effect on page load or a smooth transition between sections, enhanced with Lottie file animations of cherry blossoms falling or ink wash painting effects, creating a visually engaging experience.
